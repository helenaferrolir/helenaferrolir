COMO ABRIR
-------------------------------------------------
Basta dar dois cliques no arquivo "index.html".
Ele abre no navegador de qualquer computador (Windows, Mac ou Linux),

(a internet so deixa as fontes com o visual original).

-------------------------------------------------
O QUE TEM NESTA PASTA
-------------------------------------------------
index.html  -> o site inteiro (visual, textos, sua foto e funcionamento,
                tudo junto num arquivo so)
imagens/    -> pasta para guardar as logos das empresas quando quiser
                trocar os monogramas do carrossel de Experiencia

-------------------------------------------------
COMO ADICIONAR UM PROJETO NOVO NO CARROSSEL DE CASOS
-------------------------------------------------
1. Abra "index.html" com o Bloco de Notas (ou VS Code).
2. Procure por: const PROJECTS
3. Copie um bloco inteiro { ... } que ja esta la e cole logo abaixo,
   separando com virgula.
4. Preencha os campos:

   client       -> nome do cliente
   status       -> "ok" (selo verde) ou "mid" (selo amarelo)
   statusLabel  -> texto do selo, ex: "Onda 1 aprovada"
   title        -> nome do projeto
   problem      -> qual era o problema
   solution     -> o que voce resolveu
   metrics      -> ate 3 numeros de destaque
   detailPoints -> topicos que aparecem no modal "Ver detalhes"

5. Salve e atualize a pagina no navegador. Pronto.

-------------------------------------------------
COMO ADICIONAR/EDITAR UMA EXPERIENCIA PROFISSIONAL
-------------------------------------------------
1. Procure por: const EXPERIENCE
2. Copie um bloco { ... } e preencha: period, company, role, initials,
   logo (deixe "" para mostrar so as iniciais) e desc.
3. Salve e atualize a pagina.

-------------------------------------------------
TROCAR SUA FOTO
-------------------------------------------------
Procure por: id="avatarSlot"
Troque a tag <img ...> por outra apontando para um arquivo local, ex:
  <img src="imagens/helena.jpg" alt="Helena Oliveira">
(salvando a nova foto dentro da pasta imagens/)
