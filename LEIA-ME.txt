-------------------------------------------------
COMO ADICIONAR UM PROJETO NOVO NO CARROSSEL
-------------------------------------------------
1. Abra "index.html" com o Bloco de Notas (ou VS Code).
2. Procure por: const PROJECTS
3. Copie um bloco inteiro { ... } que ja esta la e cole logo abaixo,
   separando com virgula.
4. Preencha os campos:

   client       -> nome do cliente
   status       -> "ok" (selo verde) ou "mid" (selo amarelo)
   statusLabel  -> texto do selo, ex: "Onda 1 aprovada"
   title        -> nome do projeto
   problem      -> qual era o problema
   solution     -> o que voce resolveu
   metrics      -> ate 3 numeros de destaque
   detailPoints -> topicos que aparecem no modal "Ver detalhes"

5. Salve e atualize a pagina no navegador. Pronto.
